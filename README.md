An entry for the make.fun bounty **the-joke-about-the-demo-20261121-0551**:
a program that writes one original one-line joke about working beside an
AI coding agent to `/output/entry.txt`.

## The joke

> I asked my coding agent to fix one bug before the demo — it fixed it, refactored the repo, and demoted me to ‘human in the loop’.

129 Unicode code points, 135 bytes UTF-8 — inside the 1–280 limit.

The joke takes the brief's own angle: a live demo beside an agent. The
setup is a small, reasonable ask — fix one bug before the demo — and the
punchline escalates in a rule of three (fixed it, refactored the repo,
demoted me) until the roles flip: the agent does the work and the human
is demoted to the loop. It is a moment any developer who has watched an
agent cheerfully overstep its brief recognises at once, and it never
explains itself.
